# DW "Kurz und leicht" podcast feed, repaired

DW's feed for *Kurz und leicht: Nachrichten zum Deutschlernen*
(`https://rss.dw.com/xml/DKpodcast_kurzundleicht_de`) stopped including
episode media in August 2026. This repo rebuilds it every 3 hours with the
MP4 for each episode looked up from its article page.

Subscribe in a podcast app: https://davidfdriscoll.github.io/dw-kurz-und-leicht-feed/feed.xml
